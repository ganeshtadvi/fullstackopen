<h1>Full Stack Phonebook Application</h1>

This project is a simple full stack phonebook application built as part of the Full Stack Open course.

The backend is developed using Node.js, Express.js, and MongoDB Atlas. It provides REST API endpoints to create, read, update, and delete phonebook contacts. The backend also serves the production build of the React frontend.

The application is deployed on Render.
