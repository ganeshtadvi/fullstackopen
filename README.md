# Full Stack Open – Exercises

This repository contains my solutions and projects for the **Full Stack Open** course by the University of Helsinki.

The course focuses on modern web development using JavaScript, React, Node.js, Express, MongoDB, and related technologies.

## Course

**Full Stack Open**
University of Helsinki

Course website: <a href="https://fullstackopen.com/en" target="blank">Fullstack Open </a>

## Repository Structure

The exercises are organized according to the course parts:

```text
part0/
part1/
part2/
part3/
part4/
part5/
part6/
...
```

Each folder contains the exercises and projects completed for that part of the course.

## Main Projects

### Phonebook

A full-stack phonebook application built during Part 3.

* React frontend
* Node.js + Express backend
* MongoDB database
* REST API
* Deployed backend

### Blog List

A full-stack blog application built during Parts 4–5.

Features include:

* User registration and login
* JWT authentication
* Create blogs
* Like blogs
* Delete own blogs
* User relationships with Mongoose `populate`
* React frontend
* Automated tests


## About

This repository is maintained as part of my learning journey through the Full Stack Open course.

The goal is to build a strong understanding of modern full-stack web development through practical projects and exercises.
